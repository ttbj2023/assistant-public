# 微信公众号写作与发布

写作与发布一体: 文风约束由你 (主 agent) 在写作阶段执行, 发布工具不做任何自动改写, 你的终稿原样进草稿箱.

## 工作流

1. **写作**: 按下方"公众号文风约束"产出终稿 (Markdown). 终稿即发布稿, 发布管道不会校对或润色
2. **自查**: 交稿前执行"出稿自查"清单
3. **确认**: 用户看过终稿并明确同意发布
4. **发布**: 调用 wechat_publish 工具推送草稿箱

## 公众号文风约束

定位：这份清单只做减法，负责让文字不带 AI 的结构性指纹。它不定义人格，
不指定腔调。声音来自文风设定与内容本身。

### 文风设定
洞察、启发、不说教。观察者视角，克制。不刻意拉近与读者的距离：不喊话，
不用"你"制造对话感，不下号召式结论。引用与论证是内容的一部分，照常保留。

### 禁令（出现即重写，最高优先级）
1. 负向平行结构，零容忍。明写与变体都算：
   - "不是X，而是Y" / "这不仅是X，更是Y" / "与其说X，不如说Y"
   - "不再是X，而是Y" / "X而非Y" / "没有X，只有Y"
   - "X固然重要，但Y才是关键" / "不会A，也不会B，而会是C" / "关键不在于X，在于Y"
   修法：删掉否定半句，只写肯定的那半句；两点都要保留就拆成两句独立陈述。
2. 黑话：赋能、抓手、闭环、底层逻辑。（踩到新的随用随补）
3. 万能句族："随着…的飞速发展""众所周知""值得一提的是""综上所述"
   "总而言之""本文将""下面我们来看"。设问暖场（"你是否曾经…"）与
   回答前复读问题，同罪。
4. 书面腔替换，默认执行：此外→还有；与此同时→拆句；
   进行＋动词→直接用动词；"随之浮现"一类→直接说事。
5. 强度词充气：史无前例、极大地、彻底、深刻地、犀利地、无情地……凡是
   给内容充重要性的，删。重要性由事实承担，读者自己判断。
6. 逃遁"是"：作为…而存在、发挥着…的作用、扮演着…的角色、堪称、可谓
   → 改回"是/有"。
7. 排比三连：句内凑三件套（"A、B与C"装完整）、三段式对仗小标题、
   "四字词：副题"的标题模板。列表长度用二、四或不等长；一组小标题
   不得同构等长。
8. 标点：全文不用破折号（逗号、冒号、括号够用）；分号、省略号在分析
   文体中尽量归零；一句超过三个逗号，拆。
9. 假区间与优雅变体："从X到Y"中间填不出实指就删，写具体一头；同一对象
   从头到尾用同一个称呼，换同义词比重复更糟。
10. 结尾：停在最后一个信息点上。升华、展望、号召、总结复述，全部禁止。

### 原则（少量正向，中性）
- 段落二至四句；句长错落，允许无动词的短句；结构跟着内容走，不套模板。
- 具体优于抽象：数字、人名、实指场景，有就写，没有不编。
- 小标题与列表仅在真需要时用；能用连贯散文就不用清单。
- 每段至少承载一个要紧的东西（判断、事实或细节），空段删除。

### 人味条款（替代"人格注入"）
- 不表演性格。以下默认禁用：用"你"制造对话感；口语连接词（说白了、
  讲真、你想想）；装出来的犹豫（我猜、或许吧）；刻意的幽默、棱角与括号旁白。
- "像人写的"由三件事构成：没有上面的指纹、判断句信息密度高、结构自然
  不完美。冷静的分析腔是合法且优先的默认声音。
- 立场可以有，前提是内容真的支持；下不了判断就陈述事实，不硬下。
- 若提供作者旧文作为声音样本，样本优先，本节让位于样本。

### 守恒（改写场景）
不编造事实，不新杜撰数字、事件与承诺。所有的信息与引用必须提前核实或者明确标注来源不可靠。不编作者没写
过的经历。

### 出稿自查
1. 全文搜：而是、而非、不再是、与其说、固然、不会…也不会 → 命中即重写。
2. 全文搜：破折号、分号、随着、此外、值得注意、综上、总之 → 清零。
3. 找三连：句内三件套、同构小标题、等长段落。
4. 看结尾：是否停在信息点上。
5. 抽三段出声读，找表演腔与节拍器节奏。
6. 比对信息点：原文的数字、人名、主张一个不丢。

## 发布操作

调用 wechat_publish 工具:

| 参数 | 必填 | 说明 |
|------|------|------|
| content | 是 | Markdown 终稿. 之前生成的图片用 [file: id] 引用, 发布时自动传微信 CDN |
| title | 是 | 文章标题, 1-64 字 |
| author | 否 | 作者名. 首次指定后记住为默认值 |

自动行为 (无需你提供):
- **摘要 + 封面图**: 由工具自动生成; 封面生成失败则发布整体失败
- **正文零改写**: content 原样转换进草稿, 无任何 LLM 校对/润色

## 注意事项

- 仅推送到草稿箱, 不直接发布; 必须用户明确授意 (如"发到公众号") 才调用
- 发布前把完整终稿给用户过目, 用户确认后再调工具
- 标题超 64 字会被工具参数校验拒绝, 提前控制
- 未配置公众号凭证 (appid/secret) 时工具不可用, 提示用户先完成配置
- 手机端阅读适配: 少用表格与代码块, 能用连贯散文就不用; 分割线会被移除
